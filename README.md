### Задание 1. Кастомная модель пользователя
- Создано приложение `users` для работы с учётными записями.
- Реализована модель `CustomUser` на базе `AbstractUser`: электронная почта используется как основное поле для авторизации (вместо username).

- Модель зарегистрирована в админ-панели и корректно отображается при управлении пользователями.

---

### Задание 2. Система аутентификации и отправка писем
- **Регистрация:** реализована форма регистрации с полями email и пароля; логика сохранения пользователя вынесена в представление `RegisterView` (на базе `CreateView`).
- **Приветственное письмо:** после успешной регистрации автоматически отправляется email через SMTP (Django `MAILERS`). Отправка выполняется в методе `form_valid` через `send_mail` с явным указанием отправителя из переменных окружения.
- **Авторизация:** настроен вход по email и паролю с использованием кастомного представления `CustomLoginView` (наследник `LoginView`).
- **Безопасность:** учётные данные почтового сервиса вынесены в `.env`; SSL‑соединение обеспечивается через `certifi` (актуально для macOS).

---

### Задание 3. Контроль доступа к управлению продуктами
- **Общедоступный доступ:** страница списка товаров (`ProductListView`) доступна анонимным пользователям.
- **Закрытый доступ:** операции создания, просмотра деталей, редактирования и удаления товаров (`ProductCreateView`, `ProductDetailView`, `ProductUpdateView`, `ProductDeleteView`) защищены с помощью `LoginRequiredMixin`.
- **Механизм защиты:** миксин размещён первым в цепочке наследования CBV, что гарантирует проверку авторизации до выполнения основной логики представления.
- **Редирект:** неавторизованные пользователи автоматически перенаправляются на страницу входа (`LOGIN_URL`).
